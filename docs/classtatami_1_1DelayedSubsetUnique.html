Detailed Description

template<typename Value_, typename Index_, class SubsetStorage_>
class tatami::DelayedSubsetUnique< Value_, Index_, SubsetStorage_ >

Delayed subsetting of a matrix with unique indices.

Implements delayed subsetting (i.e., slicing) on the rows or columns of a matrix, given a vector of unique indices. This operation is "delayed" in that it is only evaluated when data is extracted from the matrix.

Template Parameters
Value_Type of matrix value.
Index_Integer type of index value.
SubsetStorage_Vector containing the subset indices. Any class implementing [, size(), begin() and end() can be used here.
