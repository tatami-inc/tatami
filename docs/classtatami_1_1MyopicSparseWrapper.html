Detailed Description

template<typename Value_, typename Index_>
class tatami::MyopicSparseWrapper< Value_, Index_ >

User-friendly wrapper around a MyopicSparseExtractor.

Template Parameters
Value_Numeric type of the matrix value.
Index_Integer type of the row/column indices.

Each instance of this class automatically allocates the buffer(s) to be used in MyopicSparseExtractor::fetch().
