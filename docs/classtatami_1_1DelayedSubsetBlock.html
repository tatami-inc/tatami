Detailed Description

template<typename Value_, typename Index_>
class tatami::DelayedSubsetBlock< Value_, Index_ >

Delayed subsetting to a contiguous block.

Implements delayed subsetting (i.e., slicing) of a matrix to a single contiguous block of rows or columns. This is a specialized implementation that is more efficient than the tatami::DelayedSubset class. This operation is "delayed" in that it is only evaluated when data is extracted from the matrix.

Template Parameters
Value_Type of matrix value.
Index_Integer type for the row/column indices.
