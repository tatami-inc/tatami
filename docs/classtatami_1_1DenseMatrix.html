Detailed Description

template<typename Value_, typename Index_, class Storage_>
class tatami::DenseMatrix< Value_, Index_, Storage_ >

Dense matrix representation.

Template Parameters
Value_Type of the matrix values.
Index_Type of the row/column indices.
Storage_Vector class used to store the matrix values internally. This does not necessarily have to contain Value_, as long as the type is convertible to Value_. Methods should be available for size(), begin(), end() and []. If a method is available for data() that returns a const Value_*, it will also be used.

Returns
Number of rows.

It is expected that the number of rows can be represented by a std::size_t without overflow, even if Index_ is of a larger size. This is implied by the fact that MyopicDenseExtractor::fetch() and friends accept a pointer for their buffer arguments; the length of the array referenced by these pointers (possibly equal to the number of rows) must fit in a std::size_t.

◆ is_sparse_proportion()

template<typename Value_ , typename Index_ , class Storage_ >
double tatami::DenseMatrix< Value_, Index_, Storage_ >::is_sparse_proportion ( ) const
inlinevirtual

Returns
Approximate proportion of the matrix that is sparse.

This is defined as the proportion of matrix elements that lie within sparse submatrices. It is intended for use in Matrix representations that consist of combinations of multiple submatrices (e.g., DelayedBind), allowing them to derive a suitable value for is_sparse() based on whether most of its submatrices are sparse. (A more granular approach would be to report the density of structural non-zero elements, but this may not be known by all representations at construction time.)

Implements tatami::Matrix< Value_, Index_ >.

◆ prefer_rows_proportion()

template<typename Value_ , typename Index_ , class Storage_ >
double tatami::DenseMatrix< Value_, Index_, Storage_ >::prefer_rows_proportion ( ) const
inlinevirtual

The return value of this method is the (approximate) proportion of matrix elements that lie within submatrices that prefer row-level access. It is useful for determining the return value of prefer_rows() in combined matrices consisting of both row- and column-preferred submatrices. In such cases, the net preference can be determined based on the combined size of the submatrices for each preference. (A more granular approach would be to report the iteration cost on each dimension, but this is difficult to estimate.)

Returns
Approximate proportion of the matrix that prefers row-level access.
