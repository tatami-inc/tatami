Detailed Description

template<typename OutputValue_, typename InputValue_, typename Index_, class Helper_ = DelayedUnaryIsometricOperationHelper<OutputValue_, InputValue_, Index_>>
class tatami::DelayedUnaryIsometricOperation< OutputValue_, InputValue_, Index_, Helper_ >

Delayed isometric operation on a single matrix.

Implements any operation that preserves the shape of the matrix and operates on each matrix value independently. This operation is "delayed" in that it is only evaluated during data extraction, e.g., with MyopicDenseExtractor::fetch() or friends. We only consider "unary" operations that involve a single Matrix - see DelayedBinaryIsometricOperation for operations between two Matrix instances.

This class is inspired by the DelayedUnaryIsoOp classes from the DelayedArray Bioconductor package.
