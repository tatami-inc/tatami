Detailed Description

template<typename Value_, typename Index_>
class tatami::DelayedTranspose< Value_, Index_ >

Delayed transposition of a matrix.

Implements delayed transposition of a matrix. This operation is "delayed" in that it is only evaluated during data extraction.

Value_Type of matrix value.
Index_Type of index value.
